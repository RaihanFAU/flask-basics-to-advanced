# Flask Basics to Advanced

This repository contains my Flask learning journey and practice projects. I am using it to understand the fundamentals of Python web development and gradually move toward building REST APIs and more advanced Flask applications.

## What I Have Learned So Far

- What Flask is and why it is used
- Basic understanding of WSGI and Jinja2
- Creating and running a Flask application
- Using `Flask(__name__)`
- Creating routes and multiple pages
- Using `render_template()`
- Working with HTML templates
- Handling `GET` and `POST` requests
- Working with HTML forms
- Accessing form data using `request.form`
- Using `redirect()` and `url_for()`
- Understanding Flask debug mode
- Using virtual environments and `requirements.txt`
- Understanding common Flask errors and debugging them
- Working with JSON using `jsonify()`
- Building basic REST API endpoints
- Using HTTP methods:
  - GET
  - POST
  - PUT
  - DELETE
- Creating, retrieving, updating, and deleting data
- Understanding basic CRUD operations
- Using dynamic routes with IDs
- Testing Flask APIs with Postman
- Basic understanding of HTTP status codes
