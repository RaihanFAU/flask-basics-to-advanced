- Creating routes and multiple pages
- Using `render_template()`
- Working with HTML templates
- Handling `GET` and `POST` requests
- Working with HTML forms
- Accessing form data using `request.form`
- Using `redirect()` and `url_for()`
- Understanding Flask debug mode
- Using virtual environments and `requirements.txt`

## Streamlit

I have also started learning Streamlit for building simple interactive machine learning applications.

### Iris Species Classification

- Built a simple Iris species prediction app
- Used the built-in Iris dataset from Scikit-learn
- Used Pandas for dataset handling
- Trained a Random Forest Classifier
- Used Streamlit sidebar sliders for user input
- Predicted Iris species based on:
  - Sepal length
  - Sepal width
  - Petal length
  - Petal width
- Used `st.cache_data` for caching data loading
